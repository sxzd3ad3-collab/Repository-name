# مستر أحمد شعبان | Mr Ahmed Shaban

منصة تعليمية عربية متكاملة لتعلم اللغة الإنجليزية: موقع عام + حساب طالب + لوحة تحكم + حجز ودفع InstaPay + مراجعة الإيصالات + تفعيل الكورسات.

## التشغيل

```bash
cd platform
npm install
npx prisma generate
npx prisma db push
npm run db:seed
npm run dev
```

ثم افتح: `http://localhost:3000`

للإنتاج:

```bash
npm run build
npm start
```

## ملاحظات مهمة

- **InstaPay:** لا توجد بيانات دفع مخزّنة افتراضيًا. أدخل اسم الحساب والعنوان من لوحة التحكم → الإعدادات.
- **روابط السوشيال:** Instagram مضبوط على `shaban4english`. Facebook وYouTube وTikTok قابلة للتعديل من الإعدادات ولم تُخترع روابط غير مؤكدة.
- **واتساب:** `01552647559` → يفتح مباشرة عبر `wa.me`.
- **استعادة كلمة المرور:** تعمل عبر طلب يُراجع من الإدارة (إنشاء رابط أو تعيين كلمة مرور). إرسال الإيميل التلقائي يحتاج خدمة SMTP خارجية غير مضمّنة هنا.
- **الفيديوهات:** يمكن إضافة رابط يوتيوب أو رفع ملف. المحتوى المدفوع لا يظهر إلا بعد التفعيل.
- **قاعدة البيانات:** SQLite في `data/app.db` مناسبة للبداية. للإنتاج الكثيف انقل إلى PostgreSQL بتغيير `provider` في Prisma.
- **الملفات الخاصة:** الإيصالات والفيديوهات المرفوعة والـ PDF تُخدم عبر مسارات محمية، وليست مجلدًا عامًا.
